# Financial Data Analysis Demo

## 项目简介
用 Python 对金融数据进行探索性分析与策略回测，7 天速成面试作品。

## 目录结构
data/               ← 原始 CSV、SQL 备份  
notebooks/          ← Jupyter 分析脚本  
src/                ← 可复用函数 & SQL 片段  

## 运行步骤
1. 克隆仓库  
   git clone https://github.com/<你的用户名>/financial-data-analysis-demo.git  
2. 安装依赖  
   pip install -r requirements.txt  
3. 依次运行 notebooks 里两个 .ipynb 文件
